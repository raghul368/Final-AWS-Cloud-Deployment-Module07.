Final AWS Cloud Deployment Project

A demonstration project showing how a static website and a serverless API can be deployed using AWS cloud services, with security and monitoring considerations.

Project Overview

🪣

Amazon S3

Host the static website files and store project assets in an S3 bucket.

⚡

AWS Lambda

Run backend application code on demand without managing servers.

🔗

API Gateway

Provide an HTTP endpoint that invokes the Lambda function.

🔐

AWS IAM

Use roles and least-privilege permissions to control access.

📊

CloudWatch

Collect Lambda logs and monitor function activity.

☁️

Cloud Deployment

Separate frontend hosting from backend API execution.

AWS Architecture

High-level architecture for the sample deployment.

User / Web Browser
↓
Amazon S3 – Static Website
↓ API request
Amazon API Gateway
↓ Invoke
AWS Lambda Function
↓ Logs
Amazon CloudWatch

Implementation Workflow

1. Prepare the website

Review the HTML files in the website folder.

2. Create an S3 bucket

Upload website files and configure static website hosting or use a suitable secure hosting setup.

3. Create a Lambda function

Use the sample Python handler in the lambda folder.

4. Configure API Gateway

Create an HTTP API route and connect it to the Lambda function.

5. Apply IAM permissions

Use least-privilege roles and avoid public access to backend resources.

6. Monitor and test

Test the website and API endpoint; review execution logs in CloudWatch.

Important: This repository contains starter code and deployment documentation. It does not create AWS resources automatically. Configure services in your AWS account, review pricing, and follow AWS security guidance before making resources public.

Project Learning Outcomes

  • Build and prepare a cloud-based application.
  • Understand how S3, Lambda, and API Gateway work together.
  • Apply IAM roles and least-privilege permissions.
  • Understand basic CloudWatch logging and monitoring.
  • Document cloud architecture and deployment steps.
